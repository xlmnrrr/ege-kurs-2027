# АРХИТЕКТУРА — «ЕГЭ курс 2027» (этап 4)
> 05.11.2026. Короткая спецификация каркаса перед кодом. Стек: HTML/CSS/JS без фреймворков и сборщика на сайте; Node-скрипты только для сборки контента и проверки. Дизайн — `DESIGN.md`, рисунки — `DRAWINGS.md`, формат номера — скилл `ege-kurs`.

## 1. Требования
**Функции** (ТЗ п.6–10): вход по паролю + настоящее шифрование контента; «запомнить устройство»; прогресс общий для ПК и iPhone; офлайн и «На экран Домой»; план на каждый день до экзаменов (2 ч/день, 5–6 дней, пересборка при пропуске); повторение ошибок 1/3/7/21; серия, уровни, прогресс к 90; заметки, закладки, «мой лист формул», печать А4; калькулятор физики (2 режима); озвучка; звуки (выключаемые); главная — 3D-карта «Две орбиты»; без внешних CDN.
**Нефункциональные**: один пользователь, 2 устройства; работает без сети; первая загрузка оболочки ≤ 300 КБ сжатого (без контента номеров); вход ≤ 1 с на iPhone; ничего из КАГ и незашифрованного контента на хостинге; бесплатно.
**Ограничения**: статический хостинг (Yandex Object Storage, запасной — GitHub Pages); сервер синхронизации — одна функция (сейчас локальный Node).

## 2. Компоненты и поток данных
```
контент\<предмет>\NN\ (md, json, js)  ──tools\build.mjs──►  data\enc\<id>.bin (AES-GCM)   ◄── браузер расшифровывает
          KaTeX пререндер, сборка номера в JSON                data\catalog.bin (оглавление, тоже шифр)
справки\ключ-данных (K, 256 бит)  ─────────────────────────►  (только для сборки, в git нет)
tools\set-password.mjs (пароль вводит Макар) ──► data\keys.json { соль, итерации, wrappedK, версия }

Браузер:  пароль ─PBKDF2-SHA256 600k─► KEK ─AES-GCM─► K (неизвлекаемый CryptoKey → IndexedDB «устройство запомнено»)
          K ─► расшифровка catalog.bin и номеров по запросу; рисунки номера = JS-модуль внутри пакета → Blob URL → import()
          прогресс: журнал событий в IndexedDB ─(шифр K)─► POST /sync ◄─► сервер хранит непрозрачные записи
Service Worker: оболочка + все .bin в кэше (cache-first, версия сборки), офлайн-очередь синхронизации
```

## 3. Решения (ADR коротко)
1. **Шифрование: ключ данных K + обёртка паролем.** Контент шифруется один раз ключом K; пароль только «обёртывает» K. Смена пароля = перешифровать 32 байта, а не весь курс. PBKDF2-SHA-256 600 000 итераций (рекомендация OWASP 2023+ для PBKDF2-SHA256), соль 16 байт; AES-GCM 256, IV 12 байт случайный на каждый файл. Argon2 был бы сильнее, но нужен WASM (+вес) — для одного пользователя с длинным паролем PBKDF2 достаточно. *Пересмотреть*, если появится публичный доступ к ссылке.
2. **«Запомнить устройство»** = неизвлекаемый CryptoKey K в IndexedDB (JS не может прочитать байты ключа). Пароль нигде не хранится. «Выйти на этом устройстве» удаляет ключ.
3. **Пароль не знает никто, кроме Макара**: `set-password.mjs` спрашивает пароль в терминале (ввод скрыт) и пишет только `keys.json`. Для разработки — тестовый пароль в `справки\` (заменяется перед публикацией).
4. **Прогресс = журнал событий (только добавление)** `{id, t, dev, type, data}`; состояние вычисляется сворачиванием. Синхронизация — объединение множеств по `id` (без конфликтов); заметки — «последняя запись по времени». Сервер не понимает содержимое (шифротекст), хранит записи и курсор.
5. **API синхронизации** (одинаковое для локального Node и Cloud Function): `POST /sync {after: <курсор>, push: [{id, blob}]}` → `{cursor, pull: [{id, blob}]}`; авторизация — `token = HMAC(K, "sync")` в заголовке (сервер хранит хэш токена; угадать без пароля нельзя).
6. **Контент номера** — один зашифрованный пакет на номер (`m01.bin`, `f26.bin`): текст (HTML с готовыми формулами), задачи, код рисунков. Грузится по требованию, кэшируется SW. Оглавление `catalog.bin` — маленькое.
7. **Рисунки** — движок «Чертёж» (`assets\js\chertezh.js`, в оболочке); код рисунков номера — внутри пакета → `import()` из Blob URL (CSP `script-src 'self' blob:`). Three.js — только на страницах с 3D-сценой, лениво.
8. **Одна страница-оболочка** `index.html` + маршруты по `#` (`#/`, `#/м/3`, `#/ф/26/тренажёр`, `#/план`, `#/заметки`, `#/пробник`). Меньше файлов (меньше платных чтений бакета), офлайн проще. F5 возвращает на тот же маршрут.
9. **План** вычисляется каждый день заново из состояния (даты экзаменов, дни занятий, освоение номеров, очередь повторения) — пропущенный день автоматически «пересобирает» план, хранить нечего.
10. **Повторение 1/3/7/21**: ошибка → задача в очередь на +1 день; верно при повторе → следующий интервал (3, 7, 21), ошибка → снова +1; после 21 — освоено.
11. **Звуки** — синтез WebAudio (без файлов), **озвучка** — `speechSynthesis` (ru-RU; для формул — текст-озвучка, собранный при сборке).
12. **Без внешних запросов**: шрифты, KaTeX, Three.js локально; CSP `default-src 'self'`.

## 4. Данные
- `keys.json`: `{v:1, kdf:"PBKDF2-SHA256", iter:600000, salt, iv, wrapped, check}` (`check` — шифр известной строки для быстрой проверки пароля).
- Пакет `.bin`: `[1 байт версии][12 IV][шифротекст+тег]`, внутри JSON `{id, title, html, tasks[], figures: "<js>", speech: {...}}`.
- IndexedDB `ege`: `keys` (K), `events` (журнал), `outbox` (неотправленные), `meta` (курсор, устройство, настройки).
- Событие: `answer {task, ok, given, hints}`, `step {num, part}`, `known {num, score}`, `note {key, text}`, `mark {key, on}`, `formula {key, on}`, `day {date, minutes}`, `mock {subject, primary, test, minutes}`, `diag {subject, num, level}`, `setting {key, value}`.

## 5. Ошибки и отказ
Неверный пароль — понятное сообщение без подробностей; 5 неверных подряд — пауза 30 с (защита от перебора на устройстве). Нет сети — всё работает, синхронизация ждёт в `outbox`, значок «не синхронизировано». Повреждённый пакет — сообщение «обнови страницу», SW подтянет заново. Обновление сайта — SW показывает «Доступна новая версия» с кнопкой.

## 6. Проверка (готово = проверено)
`tools\e2e.mjs` (headless Chrome, iPhone и ПК): вход неверным/верным паролем, «запомнить», выход; расшифровка номера; шаги рисунка; ответ верно/неверно/подсказки; повторение по датам (подмена времени); план при пропуске дня; синхронизация двух «устройств» через локальный сервер; офлайн (SW); калькулятор; печать (эмуляция print); ни одного внешнего запроса; консоль без ошибок; ширины 320/393/1440 без горизонтальной прокрутки.
